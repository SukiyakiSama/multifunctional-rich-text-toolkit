# Multifunctional Rich Text Toolkit

多功能富文本标签工具网站：富文本预览、图片与像素文字转换、颜色收藏、色表、渐变预设和撤销/重做。

直接用浏览器打开 `index.html`。网页为单文件应用，转换、预览和下载均在本地完成，无需启动 Python 或服务器。

## 使用

1. 在「图片 → 富文本」区域选择、拖入图片，或添加文件夹；支持多张图片。
2. 设置网格列数、行数，点击「转换并预览」。生成的文字会载入下方编辑器，右侧自动显示像素图。
3. 多张图片可通过「当前图片」切换。使用「复制富文本」「下载 TXT」导出编辑器当前内容，或使用「下载全部 TXT（ZIP）」保存已转换图片的结果。
4. 右侧可调整预览缩放并导出 PNG。也可通过「导入 TXT」查看已有的颜色方块文字。
5. 黑色输入框上方提供「撤销」「重做」按钮。`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；Mac 使用 `⌘Z` / `⌘Shift+Z`。添加渐变、颜色、字号等格式，以及输入、清空、导入和载入转换结果，都可以撤销，文字选区会一并恢复。

ZIP 保存转换时的结果；之后在编辑器内修改的文字请单独下载 TXT。清空图片列表不会清空编辑器。

连续输入会合并为一个撤销步骤，中文输入法的候选过程合并到一次提交中。历史最多保留 100 步，长文本还会按存储预算淘汰较早的记录；刷新页面会清空历史。

## 常用颜色与渐变

黑色输入框中的「常用颜色」「渐变设置与预设」均可点击标题展开或收起，网页会记住展开状态。

- **色表**：原有调色盘旁新增「色表」按钮，提供 80 个灰阶、基础色和深浅变化色块，悬停可查看 HEX。工具栏色表直接改变选中文字的颜色；收藏区色表填入待保存颜色；渐变色点旁的色表改变对应色点，再点击「应用渐变」更新正文。支持方向键移动、Enter 选色、Esc 关闭。
- **常用颜色**：选中文字后，点击一个色块即可应用。可用颜色选择器或 HEX 输入框选色，填写可选名称后保存；工具栏选过颜色后，点击旁边的 `☆` 可以直接收藏。点击色块右侧的 `×` 删除收藏，同一颜色重复保存会更新名称。
- **渐变选色**：打开渐变设置，可设置 2–6 个等距色点。每个色点可以使用颜色选择器、HEX 输入框或常用颜色下拉列表；支持增加、删除色点和反转颜色。设置完成后点击「应用渐变」，工具栏 `◒` 也会应用当前配置。
- **渐变预设**：点击预设名称立即应用，点击旁边的「调色」只载入设置。保存时会一并记录颜色列表和输出方式；同名保存会更新该预设，`×` 可删除。预设保存在当前浏览器本地，刷新后保留。

| 渐变方式 | 输出与显示 |
| --- | --- |
| `<gradient>` 标签 | 使用一个 `<gradient=#起点,#终点,...>文字</gradient>` 包裹选区，在网页中通过 CSS 显示连续渐变 |
| 逐字 `<color>` | 沿整个选区按字符顺序插值，每个字符输出独立的 `<color=#RRGGBB>字</color>`，可用于只支持颜色标签的环境；标签数量更多 |

例如，红色到蓝色的逐字渐变应用于 `甲乙丙`，输出：

```text
<color=#ff0000>甲</color><color=#800080>乙</color><color=#0000ff>丙</color>
```

逐字渐变在 RGB 通道中线性插值，首尾字符使用首尾颜色。换行和 `<br>` 原样保留且不占渐变步数，空格占一个步数；单个字符使用起始颜色。支持 `Intl.Segmenter` 的浏览器会按完整字形分段，避免拆开 emoji、组合重音等字符，旧浏览器回退为 Unicode 码点分段。其他格式标签会保留，不会被当成文字逐字着色。

连续应用颜色或渐变时，会替换选区中的旧颜色、渐变标签；选区恰好位于一层颜色或渐变包装内时，也会替换该包装。应用后保留选区，便于一次选中后连续试色。每次应用都可撤销；保存或删除预设不会改变正文，也不计入正文撤销历史。

## 原转换器结构

图片转换功能依据配套的「富文本转换器 V1.1」Python 源码和配置移植；本仓库中的网页可独立运行。

| 文件 | 职责 | 网页中的对应实现 |
| --- | --- | --- |
| `img2richtext.py` | 核心转换：图片缩放、颜色量化、边缘泛洪去黑底、编码、校验、预览；也提供命令行入口 | `sampleImage`、`removeBorderBackground`、`encodePixels`、`convertImageEntry`，以及已有的像素预览解析器 |
| `img2richtext_gui.py` | Tkinter 界面：文件列表、参数、批量处理、复制、输出目录、配置保存 | 图片转换面板、批次列表、下载按钮和本地设置保存 |
| `img2richtext_config.json` | 保存网格、字号、行高、阈值、上移、流式标签等选项 | 初始参数沿用该配置；之后使用浏览器 `localStorage` 记住设置 |
| `点击启动转换器.exe` | 提供的 Windows 可执行入口 | 网页独立运行，不依赖此文件；移植使用上述源码，未执行或反编译 EXE |

## 编码规则

- 双线性缩放到指定网格。缩小时扩大三角滤波器范围，横纵分两遍处理，分别舍入到 8 位通道值。
- RGB 每通道按 `floor(value / 16) * 16` 量化到 0、16、32、…、240。
- 去黑底在量化之后进行：RGB 三通道均严格小于阈值的像素才视作深色。从四周边缘出发，按上、下、左、右四个方向泛洪；封闭的内部深色细节保留。
- 每个像素输出一个 `█`，每行严格输出指定列数；透明像素使用 `<color=#00000000>█`，不用空格代替。
- 流式格式仅在颜色发生变化时插入 `<color=#RRGGBB>`，颜色状态跨行保留，末尾统一输出一次 `</color>`。
- 关闭流式格式时，每行的连续同色段独立输出 `<color=...>██…</color>`。
- 外层使用 `<size=5%><line-height=50%>…</line-height></size>` 等标签。上移格数非零时，额外写入 `<voffset=...em>`；换算为 `上移格数 × 字号 / 100 × 行高 / 100`，保留两位小数。

右侧像素预览识别这些包装标签，按正方形像素还原图案。字号、行高和上移参数写入导出的文字，供目标富文本组件使用；它们不改变网页像素图的尺寸与位置。预览 PNG 的原生尺寸就是网格大小，预览缩放不会改变 PNG 的分辨率。

## 参数与边界

| 参数 | 初始值与行为 |
| --- | --- |
| 网格 | 70 × 70；每边允许 1–1,024 格 |
| 字号 / 行高 | 5% / 50%，分别允许 1–100% / 1–200% |
| 去除周围黑底 / 阈值 | 开启 / 64；阈值允许 0–255 |
| 上移格数 | 0，允许 0–9,999 |
| 流式颜色标签 | 开启 |
| 保留图片透明区域 | 开启；保留 Alpha，必要时输出八位 HEX 颜色 |
| 保持原图比例 | 关闭；开启后，以列数为准计算行数，批量时每张图片分别计算 |

浏览器版新增了透明度保留和保持原图比例。原 Python 代码先转为 RGB，会忽略原图透明度；因此透明图不能期望与原程序逐字相同。网页保留透明度时采用预乘 Alpha 缩放，避免透明边缘出现黑边。浏览器对半透明像素的预乘、反预乘舍入，以及图片色彩管理和解码差异，也可能影响颜色量化边界。

支持 PNG、JPEG、WebP、BMP、GIF，由浏览器解码；动图转换第一帧。原图和缩放中间图均限制为最多 4,000 万像素。文件夹选择包含其中支持格式的文件。损坏图片会报告错误并继续转换其他图片。同名输出自动增加编号。

文件只保留在当前页面内存中，刷新后需要重新选择；转换参数、常用颜色、渐变预设和面板展开状态保存在浏览器。浏览器不提供桌面程序的任意输出目录写入，改为下载 TXT、PNG 或 ZIP，由浏览器控制保存位置。

## 验证

使用原 Python 转换器作为参照，对同一张不透明 RGB 测试图进行了原尺寸、放大、缩小、单像素、单轴缩放、非等比缩放共 7 种尺寸测试，两种标签格式合计 14 组。统一 Windows / Unix 换行符后，生成的文字逐字一致。此项说明针对这些已验证样例，不保证所有图像解码器的输出完全相同。

`tests/image-converter.cjs` 是浏览器集成检查，覆盖颜色跨行继承、透明度、两种标签格式、上移、四方向去黑底、阈值边界、批量比例、同名文件、损坏图片、编辑器与批次导出、旧 TXT 与普通富文本、窄屏布局、参数持久化和无网络请求。生成的截图、下载文件和 ZIP 预期内容保存在系统临时目录，检查结束会输出路径。

测试需要 Node.js 和 Playwright（仅测试需要，网页不需要）。在已提供 Playwright 的环境中运行：

```powershell
node tests/image-converter.cjs
node tests/editor-history.cjs
node tests/paint-library.cjs
node tests/color-table.cjs
```

若 Playwright 位于独立运行时，可通过 `PLAYWRIGHT_MODULE` 指定其模块目录；通过 `BROWSER_PATH` 指定浏览器可执行文件。Windows 默认测试已安装的 Edge，其他系统使用 Playwright Chromium。

`tests/editor-history.cjs` 验证渐变等格式的撤销/重做、键盘与按钮操作、选区与滚动位置恢复、输入分组、中文输入法提交、导入及清空、长像素文字、历史数量限制和移动端按钮布局。

`tests/paint-library.cjs` 验证常用颜色管理、持久化和显隐、一键换色、渐变色点和预设、两种输出方式切换、逐字插值、字形分段、格式和换行保留、撤销、无效设置处理，以及桌面和窄屏布局。

`tests/color-table.cjs` 验证色表选色、原选区保留、颜色替换与撤销、收藏和渐变预设联动、键盘操作、关闭行为，以及 320px 宽度下的弹出位置和布局。
